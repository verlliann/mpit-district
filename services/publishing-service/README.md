# Publishing Service

Микросервис для публикации контента на социальные платформы.

## 📚 Документация

**Полная документация для DevOps:** [DEVOPS.md](./DEVOPS.md)

## 🚀 Быстрый старт

```bash
# 1. Установка зависимостей
npm install

# 2. Настройка
cp .env.example .env
# Отредактируйте .env

# 3. Компиляция
npm run build

# 4. Запуск
npm start
```
